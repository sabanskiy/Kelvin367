# Contributing

- Work on a branch and open a pull request into `main`; at least one teammate looks at it before merge. Keep PRs small.
- Do not commit secrets: API keys (for example the FIRMS MAP_KEY), tokens, `.env` files. If one leaks, tell the team at once and rotate it.
- Do not commit raw data downloads. Put source and licence of every dataset in `DATA.md` first.
- Code and documentation you add are released under Apache-2.0. Do not paste code or text that you are not allowed to relicense; cite third-party material with its licence.
- Be accurate in text: say what was measured, what was not, and the limits of every result.
- Commit messages: short, imperative, in English.
