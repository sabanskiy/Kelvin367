# Fire History Map: UI design prototype

Design prototype of the Kelvin367 History screen (React, Vite, Tailwind CSS), exported from Figma Make. It is a visual prototype with placeholder data, not the working application.

## Run

```bash
pnpm install
pnpm dev
```

Open the address printed by Vite. The `.figma/` folder lets Figma Make reopen the project; keep it in the repository.
